About TaskList Stats

Statistics and event history for TaskList.

Event history

TaskList records task changes as they happen. Older history is reconstructed from saved creation, completion, cancellation, and reopening dates. Dates marked “Unknown” have no information available.

Older history may miss repeated status changes and tasks deleted before deletion tracking began in TaskList v1.5.10. Some entries have a date without a time.

These gaps affect History Explorer, Compare, Activity Sessions, and Milestones. Current task statistics use the current TaskList data.
